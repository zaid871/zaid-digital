# Auto-DM (comment-to-DM) loop

Official Meta **Private Replies** API — no password bots, no unofficial tools.
When a viewer comments the keyword (default `LINK`) on a Reel, the account
sends them **one** DM with the affiliate link. 1 reply per comment, 7-day
window, 750 calls/hour/account (Meta's published limits).

## The three pieces

### 1. Script — mandatory `dmCta`
`src/lib/pipeline/script.ts` forces every script to include
`dmCta: { keyword, ctaLine }`:
- The keyword (default `LINK`, single uppercase word) MUST be spoken in the
  final scene's narration — enforced at parse time (model retries, then the
  job fails honestly).
- `sanitizeDmCta()` price/banned-claim scans the CTA line.

### 2. Video — the CTA is visible, not just spoken
- **Voiceover + burned-in captions** carry the spoken CTA line (final scene).
- **Storyboard** appends a `💬 LINK comment karo 👇` badge to the final CTA
  scene's on-screen text (also used by the Remotion title card).
- **End-card** (`render.ts`) shows the DM CTA line instead of the generic
  CTA — it is the video's primary call to action.
- **QA** has a critical `dm-cta-present` check: keyword missing from the
  script or not spoken in narration → **FAILED** (never silently skipped).
- **Caption pack** (`caption-pack.ts`, `dmCtaLine` input): the Instagram
  caption always ends with the CTA line — appended automatically if the
  model ignored the prompt rule; a violating line is dropped, never forced.

### 3. Tool — n8n workflow `affiliate/instagram-auto-dm.json`
Generated by `scripts/gen-auto-dm.py` (12 nodes, connections + JS validated).
Two flows on one path `/webhook/affiliate/ig-comments`:
- **GET** — Meta's one-time verification handshake (`hub.verify_token`
  must equal `META_VERIFY_TOKEN`).
- **POST** — comment events → top-level comments only (replies skipped,
  own comments skipped) → word-boundary keyword match (`DM_KEYWORDS`,
  default `LINK`) → DM built from `DM_REPLY_TEMPLATE`
  (`{{username}}`/`{{keyword}}`/`{{link}}`) + affiliate link
  (`DM_LINK_MAP_JSON` per media, else `DM_DEFAULT_LINK`) + disclosure →
  `POST graph.facebook.com/v21.0/{IG_USER_ID}/messages` with
  `recipient: { comment_id }`.

**Fail-safe gates** (a blocked DM is logged, never sent):
- no affiliate link resolvable for the media → skip;
- price/offer pattern in the final DM text → skip;
- DM over 900 chars → skip.

## Deploy setup (manual, Meta dashboard)

1. In your Meta app: Webhooks → subscribe the **`comments`** field to
   `https://<n8n-domain>/webhook/affiliate/ig-comments`, verify token =
   `META_VERIFY_TOKEN`.
2. Permissions (Facebook Login flow, same app as publishing):
   `instagram_manage_comments` + `instagram_manage_messages`. Dev mode is
   enough for your own account (same as IG/FB publishing); app review only
   matters for third-party accounts. **Re-check permission names in Meta's
   docs at setup time — they rename these periodically.**
3. n8n env: `META_VERIFY_TOKEN`, `IG_USER_ID`, `IG_ACCESS_TOKEN`,
   `DM_KEYWORDS`, `DM_REPLY_TEMPLATE`, `DM_DEFAULT_LINK`,
   `DM_LINK_MAP_JSON`, `DM_DISCLOSURE`.
4. Import `instagram-auto-dm.json` in n8n and activate. Post a test `LINK`
   comment from a second account and confirm the DM arrives.

## Honest limits
- The DM may land in **message requests** depending on the recipient's
  settings — write the template so it reads fine hours later.
- One private reply per comment; if the user replies in the DM thread, a
  normal 24h conversation opens (this workflow does not auto-continue it).
- Aggressive automation on huge volumes can still draw Meta's attention —
  this loop only ever replies to people who commented first, which is the
  pattern Meta documents and allows.
- Per-video links need `DM_LINK_MAP_JSON` maintained; unwired media fall
  back to `DM_DEFAULT_LINK` or are skipped (never sent link-less).
